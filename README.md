# poopsy-core

Minimal, portable core loop for Poopsy-in-a-Box.

Goal: a clean, testable spine (observe → decide → act → learn) with strong safety rails:
- **sterile repo** (no household PII/IDs)
- probes + receipts mindset
- simple test runner
- CI gates (sanitization)

This repo is intentionally small. Product layers (wizard/console/research) live elsewhere.
